# Contributing to Awesome Sendible Alternatives

Thanks for helping improve this list! Please follow these guidelines so every entry stays useful and consistent.

## Guidelines

- **One tool per pull request.** This makes review and discussion easier.
- **It must be a real Sendible alternative.** The tool should offer social media scheduling, publishing, engagement, or reporting.
- **Pick the right section.** Add the tool to the category that best matches its main strength.
- **Follow the table format:**

  ```markdown
  | **Tool Name** | Best For | [domain.com](https://domain.com) | Short, factual highlight. |
  ```

- **Keep descriptions short and neutral.** One sentence, no marketing superlatives.
- **Check your links.** Use the official website and HTTPS where possible.
- **No duplicates.** Search the list before adding a tool.

## How to Submit

1. Fork this repository.
2. Edit `README.md` and add your tool.
3. Commit with a clear message, e.g. `Add ToolName to Scheduling & Visual Planning`.
4. Open a pull request describing why the tool belongs on the list.

## Updating or Removing Entries

If a tool has shut down, rebranded, or its description is outdated, open a pull request with the fix and a short explanation.

## Code of Conduct

Be respectful and constructive. Spam or self-promotional submissions that do not meet the guidelines will be closed.

Thank you for contributing!
